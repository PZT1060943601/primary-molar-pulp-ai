# Data Notice

This repository does not contain the original pediatric clinical radiographs.

The original images are hospital clinical records from minors. Even after de-identification, unrestricted public sharing of the original images or a representative raw-image subset is not permitted under the current ethics approval and institutional data-governance policy.

The `data/` directory contains only public reproducibility materials:

- Aggregate dataset statistics.
- Test-set class distribution and model performance summaries.
- Synthetic/example images for verifying code execution and file format.

The synthetic/example images are computer-generated phantom images. They are not real dental radiographs and must not be used for clinical diagnosis, clinical validation, or model performance claims.
