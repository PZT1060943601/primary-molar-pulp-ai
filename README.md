# Primary Molar Pulp AI

Code and public reproducibility materials for CNN-based classification of treatment-record-defined pulp involvement in primary molar deep-caries periapical radiographs.

## Study Task

This project evaluates six convolutional neural network architectures for binary classification of primary molar periapical radiographs with deep caries.

The labels are defined according to retrospective clinical treatment records:

- `0`: pulp-not-involved, corresponding to teeth treated with fillings.
- `1`: pulp-involved, corresponding to teeth treated with pulpotomy or root canal therapy.

These labels are treatment-record-defined surrogate labels and should not be interpreted as histological pulp-status labels.

## Public Data Materials

The original pediatric clinical radiographs are not included in this repository. The images were obtained from hospital clinical records of minors, and unrestricted public deposition is not permitted under the current ethics approval and institutional data-governance requirements.

To support reproducibility, this repository provides:

- Aggregate dataset statistics.
- Test-set class distribution and confusion-matrix counts.
- Model performance metrics.
- A synthetic/example dataset matching the independent test-set class distribution.

The synthetic/example dataset is intended only for testing the code pipeline and file format. It is not a clinical image dataset and must not be used for diagnostic model validation.

## Installation

Python 3.9 or later is recommended.

```bash
pip install -r requirements.txt
```

For GPU training, install a PyTorch build that matches your CUDA version. See the official PyTorch installation instructions if needed.

## Basic Usage

The main training/evaluation script is:

```bash
python code/step3_1_main_new.py --csv path/to/image_paths2.csv --output-root .
```

The dataset CSV should contain:

- `label`: binary label (`0` or `1`).
- `picture`: image path for the periapical radiograph or synthetic example image.

The public synthetic dataset can be used to verify file loading and preprocessing, but it is not intended to reproduce the clinical performance values reported in the manuscript.

The test prediction files generated by the script include both binary predictions (`*_pred`) and positive-class probabilities (`*_prob`). The probability columns can be used for ROC, PR, AUC, AP, and bootstrap confidence-interval calculations.

## Reproducibility Notes

- Random seed in the training script: `42`.
- Models evaluated: ResNet18, ResNet50, ResNet101, AlexNet, VGG16, and GoogLeNet.
- Test-set size reported in the manuscript: 505 images.
- Test-set class distribution: 267 label-0 images and 238 label-1 images.

## Data Availability Statement

The source code for preprocessing, model training, evaluation, confidence-interval calculation, and statistical analysis is provided in this repository. The original radiographic dataset cannot be publicly released because it consists of clinical dental radiographs from pediatric patients. Although direct personal identifiers were removed during data processing, the images are derived from hospital clinical records of minors, and the current ethics approval and institutional data-governance policy do not permit unrestricted public deposition of the original images or a representative raw-image subset.

To support reproducibility while protecting patient privacy, aggregate dataset statistics and a synthetic/example dataset are provided. Access to the original de-identified data may be considered only upon reasonable request, subject to approval by the corresponding institution and ethics committee and completion of an appropriate data-use agreement.
